# 오디오 가이드 — 폰즈 (FONS)

믹싱·포맷 규칙의 정본. **사운드 시스템은 아직 없다.** 여기 적힌 것은 도구·납품 규격이고,
믹싱 목표는 사운드가 들어올 때 정한다.

## 납품 규격 (확정)

| 항목 | 값 | 이유 |
|---|---|---|
| 음악·앰비언스 | OGG Vorbis, `-q:a 5` | 용량 대비 품질. Godot이 네이티브로 읽는다 |
| 짧은 SFX | WAV 또는 OGG | 반복 재생이 잦은 짧은 소리는 WAV가 디코딩 비용이 낮다 |
| 샘플레이트 | 44.1 kHz 또는 48 kHz | 프로젝트 전체에서 하나로 통일한다 |
| 루프 | 파일이 아니라 Godot `.import` 설정에 기록 | 원본을 다시 뽑아도 루프가 유지된다 |
| 원본 | `audio-source/` 에 보관 | 게임 폴더에 원본 세션을 두지 않는다 |

변환은 ffmpeg 하나로 통일한다. 도구 버전은 [SETUP.md](../../SETUP.md).

```bash
ffmpeg -i in.wav -c:a libvorbis -q:a 5 out.ogg
```

## 버스 계획 (미구현)

Godot 오디오 버스는 `Master` 아래 `Music` / `SFX` / `Voice` 로 나눌 계획이다.
지금은 기본 버스 하나뿐이라, 사운드를 넣는 시점에 `default_bus_layout.tres` 를 만든다.

## 미정

- 마스터 음량 목표(라우드니스)와 리미터 설정
- 동시 발음 수 상한과 우선순위 규칙(같은 SFX가 겹칠 때 자르기/합치기)
- 음악 전환 방식(크로스페이드 시간, 전투 진입 시 레이어링)
- 보이스 유무 — 내러티브가 정해지지 않았다
