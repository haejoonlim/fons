# ADR 0002 — 데이터 정본은 JSON 하나, 사본은 생성물

## 맥락

밸런싱 수치가 세 곳에 존재했다: 원본 저장소의 정본 JSON, 이 저장소 루트의 이관 사본,
그리고 Godot이 읽는 `godot/data/`. 손으로 세 곳을 고치면 반드시 갈라진다.
실제로 이 저장소는 한 번 **없는 정의**(소환 130회 게이트)를 근거로 삼은 적이 있다.

## 대안

1. **Godot이 루트 `data/` 를 직접 읽는다.** `res://` 밖은 읽을 수 없다. Godot 프로젝트를 루트로 올려야 하는데
   그건 [ADR 0001](0001-repo-layout.md) 과 충돌한다.
2. **심볼릭 링크.** Godot은 링크를 따라가지만, 익스포트·Windows 체크아웃에서 깨지기 쉽다.
3. **루트 `data/` 가 정본, `godot/data/` 는 `tools/sync_data.py` 가 복사한 사본.**
   복사는 `data/manifest.json` 목록만 수행하고, 하나라도 없으면 **exit 1**.

## 결정

3번. 그리고 실패를 조용히 넘기지 않는다.

- 정본: 루트 `data/*.json` + `data/manifest.json`(이관 목록)
- 사본: `godot/data/*.json` — 손으로 고치지 않는다
- 동기화: `./.venv/bin/python tools/sync_data.py --src <원본>/Data --dst godot/data`
- 검사: `tools/check_docs.py` 가 manifest 의 모든 파일이 `data/` 에 있는지 확인한다

## 결과

**얻은 것**
- "이 값이 어디서 왔나"의 답이 하나다. 문서의 수치는 `docs/original/` 사실표를 가리킨다.
- 파일이 빠지면 게이트가 실패한다. 빈 데이터로 게임이 도는 상태를 통과시키지 않는다.

**잃은 것**
- 사본이 두 벌이라 용량이 두 배다 (지금은 무시할 수준).
- 동기화를 잊으면 Godot 쪽이 낡는다. 그래서 `sync_data.py` 를 유일한 경로로 두고 손 복사를 금지한다.

**아직 안 한 것**
- 생성기 파이프라인. 원본은 생성기가 정본 JSON을 만들고 일부 필드는 사람이 손으로 채운다.
  지금 이 저장소는 **결과물만** 받는다. 생성기를 들여올 때는 손 편집 필드를 별도 오버라이드로 분리해야
  재생성 때 수동 편집이 날아가지 않는다.
