## 표시 규칙

- `(원본 대조)` — 원본 파일을 실제로 읽고 확인한 값이다. 출처 파일명을 함께 적었다.
- `(원본 미검증)` — 아직 원본에서 확인하지 못한 2차 인용이다. 이 폴더에는 없어야 정상이다.
- `(자체 실측)` — 원본 내용이 아니라 **이 머신에서 직접 돌려서** 얻은 값이다 (환경 버전·검증 로그 등).
- `원본에 없음` — 원본 어디에도 그 값이 없다는 뜻이다. (예전 세션이 만든 값이 이 경우였다.)
- 원본이 **스스로 모순**되면 한쪽을 고르지 않고 **양쪽을 병기**한다. 각 문서 끝에 그런 항목을 모아 두었다.

## 이 자료를 읽는 순서

1. 여기서 값 하나를 확인한다.
2. 그 값이 폰즈 문서·코드에 어떻게 적혀 있는지 대조한다.
3. 다르면 **이 자료가 맞다** — 이 자료가 원본이고 폰즈가 사본이다.
4. 이 자료에 없는 값이 필요하면 **추측하지 말고 원본을 다시 읽는다.**

원본을 다시 읽으려면 `~/soul-commander`에 클론이 있으면 된다. 없다면 아래를 실행한다.
SSH 키(`~/.ssh/fons_soulcommander_ed25519`) 등록이 끝난 상태였다.

```bash
git clone git@github.com:haejoonlim/soul-commander.git ~/soul-commander
```
