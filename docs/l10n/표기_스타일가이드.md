# 표기 스타일가이드 — 폰즈 (FONS)

문서·UI·데이터에 한국어를 쓸 때의 규칙. **맞춤법 검사기가 아니다.** 판단이 갈리는 지점만 정한다.
고유명사 목록은 [용어집](용어집.md)에 있다.

## 1. 정본이 먼저

- 고유명사 철자는 `data/*.json` 의 `name` / `name_ko` 를 그대로 복사한다. 손으로 다시 쓰지 않는다.
- 시스템 용어의 뜻은 `GDD_v8.0_00_확정사항.md` 가 정본이다. 이 문서와 충돌하면 GDD가 이긴다.
- `docs/gdd/` · `docs/original/` 은 원본 문면이라 고치지 않는다. 고칠 것은 새로 쓴다.

## 2. 띄어쓰기

- 데이터에 띄어쓰기가 있으면 **그 띄어쓰기를 유지**한다: `하이 엘프`, `원소 마도사`, `탑의 서고`, `영웅의 전당`, `무광심연`(붙임), `부유 이끼늪`(띄움).
- 종족·바이옴·시설 이름을 문장에 넣을 때도 쪼개거나 붙이지 않는다. `하이엘프` ✗ / `하이 엘프` ○
- 숫자와 단위는 붙인다: `130마석`, `100층`, `5인`, `3종`. 다만 단위가 한글 단어인 경우는 관행대로: `마석 130개`, `2%p`.
- 조사는 앞말에 붙인다: `풀바다에서`, `마석으로`.

## 3. 수치 표기

| 대상 | 표기 | 예 |
|---|---|---|
| 등급 | `★` + 숫자 | `★5`, `★5+`, `★1~★6` |
| 레벨 | `Lv` + 숫자 | `Lv130`, `Lv = round(층 × 1.3)` |
| 층 | 숫자 + `층` | `1~25층`, `100층` |
| 배율 | `×` | `×1.3`, `HP ×1.2` |
| 범위 | `~` | `1~65층`, `20~33.5%` |
| 확률 | `%`, 퍼센트포인트는 `%p` | `5%`, `+2%p` |
| 곱·나눗셈 | `×` · `/` | `층²×75` |
| 소수 | 마침표 | `0.04`, `3.71` |
| 천 단위 | 쉼표 | `26,000` |

`x` · `*` · `~>` 로 대신 쓰지 않는다.

## 4. 영문·외래어

- 화면 문구에는 영문을 병기하지 않는다. `마석` ○ / `마석(Mana Stone)` ✗
- 문서에서 ID가 필요할 때만 코드 표기로 쓴다: `` `race_human` ``, `` `biome_plains` ``.
- 외래어는 데이터 표기를 따른다: `리자드맨`, `뱀파이어`, `드루이드`, `노움`, `하프링`. 원어 철자를 그대로 노출하지 않는다.

## 5. 어조

- 기획·개발 문서: `~다` 평서체. `~합니다` 섞지 않는다.
- 게임 안 상태·수치 설명: `~합니다`체. 한 화면 안에서 `~다`와 섞지 않는다.
- 버튼·안내: `~하세요`체. 한 단어짜리 버튼은 명사형(`소환`, `닫기`).
- UI 문구의 최종 정본은 아직 없다(플레이테스트 전 가안). 정해지면 이 절을 갱신한다.

## 6. 직업·키워드 설명문

- 직업 설명은 `~는 직업` 으로 끝낸다. 예: `갑옷을 입고 제자리를 지키는 직업`
- 키워드 설명은 관형형(`~는` · `~은` · `~한`)으로 끝낸다.
- 자기 이름을 설명 안에서 다시 쓰지 않는다. (`철벽기사는 철벽처럼…` ✗)
- 삭제된 이름을 참조하지 않는다. 3문장을 넘기지 않는다.

## 7. 쓰지 않는 말

- 번역투: `~에 대한`, `~를 통해`, `~에 있어서`, `~되어진다`, `~할 수 있다` 남발.
- 추상 명사화: `전략적 함의`, `혁신적 접근`. 무엇이 어떻게 되는지 쓴다.
- AI 상투구: `결론적으로`, `핵심적으로`, `시사하는 바가 크다`.
- 같은 문단에서 같은 대상을 두 이름으로 부르기. 별칭은 용어집에만 둔다.

## 8. 검사

```bash
./.venv/bin/python tools/check_glossary.py     # 용어 표기가 정본에 있는지
./.venv/bin/python tools/review_docs.py        # 문서 링크·수치 충돌
```
