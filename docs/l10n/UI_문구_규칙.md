# UI 문구 규칙 — 버튼 · 에러 · 툴팁

표기(띄어쓰기·수치·어조)는 [표기_스타일가이드](표기_스타일가이드.md), 이름은 [용어집](용어집.md)이 정한다.
이 문서는 **화면에 뜨는 짧은 문장**만 다룬다. 셋이 충돌하면 이름은 용어집, 표기는 스타일가이드가 이긴다.

## 1. 세 줄 규칙

1. **한 줄에 한 가지.** 버튼 하나에 동작 둘을 넣지 않는다 (`저장 및 닫기` ✗ → `저장` + `닫기`).
2. **결과를 말한다.** 조작 이름(`클릭`, `선택`)이 아니라 일어나는 일을 쓴다.
3. **숫자는 처음에.** 수치가 있는 문구는 수치를 앞에 두고 조건을 뒤에 붙인다.

플레이테스트 전까지 이 규칙은 **가안**이다. 확정되면 이 문서를 고친다.

## 2. 버튼

| 자리 | 형태 | 예 |
|---|---|---|
| 주 동작 | 동사, 2~4자 | `소환` · `저장` · `부활` · `출전` |
| 보조 동작 | 동사, 2~4자 | `취소` · `닫기` · `되돌리기` |
| 파괴적 동작 | 동작 + 대상 | `영웅 해고` · `기록 삭제` |

- 파괴적 동작은 **색과 문구 둘 다**로 구분한다. 같은 자리에 `확인`만 두지 않는다.
- 비활성 버튼에 이유를 붙일 때는 버튼 옆이 아니라 아래에 한 줄로 쓴다: `마석이 30개 부족합니다`.
- 확인창은 같은 동사를 되풀이한다. `삭제할까요?` → `삭제` / `취소`. `예` · `아니오` ✗

## 3. 에러

두 문장을 넘기지 않는다. **무엇이 막혔는지 → 무엇을 하면 되는지.**

```
✗ 저장에 실패했습니다. (오류 코드 0x1F)
○ 서버에 저장하지 못했습니다. 잠시 뒤 다시 시도해 주세요.
```

```
✗ 잘못된 입력입니다.
○ 이름이 12자를 넘습니다. 12자 이내로 줄여 주세요.
```

- 사용자 탓을 하지 않는다: `입력이 잘못되었습니다` ✗ / `이름이 비어 있습니다` ○
- 내부 용어·코드·스택을 노출하지 않는다. 로그로만 남긴다.
- 되돌릴 수 없는 실패(세이브 손상)는 **다음 행동을 반드시 적는다**: `이전 저장으로 돌아가려면 [불러오기]를 누르세요.`
- 같은 실패가 반복되면 문구를 바꾸지 말고 원인을 고친다.

## 4. 툴팁

순서를 고정한다: **이름 → 한 줄 설명 → 수치 → 조건**.

```
전당의 은혜
100층을 처음 넘을 때 받는 재화입니다.
부활 1명 = 1개
획득: 100층 클리어
```

- 수치는 단위까지 쓴다: `AP 3` ✗ / `행동력 3` ○
- 조건은 `~때` · `~에서만` 으로 끝낸다: `무풍고원에서만 등장합니다`.
- 툴팁에 문단을 넣지 않는다. 세 줄을 넘으면 별도 패널로 뺀다.
- 확률은 반올림하지 않는다: `0.05%` ○ / `0.1%` ✗ (표기 규칙은 스타일가이드 §3).

## 5. 알림 · 토스트

- 한 줄, 40자 이내. 마침표를 찍지 않는다(문장이 아니라 상태 표시).
- 성공은 결과만: `마석 130개를 썼습니다` ✗ → `소환 완료 · ★3 겐`
- 실패는 §3을 따른다. 토스트에는 원인 한 줄만, 해결은 화면에 남긴다.

## 6. 로딩 · 빈 화면

| 상황 | 문구 |
|---|---|
| 로딩 | `불러오는 중` (말줄임표 없음) |
| 빈 목록 | `아직 없습니다` + 다음 행동 버튼 |
| 조건 미충족 | 조건을 그대로 쓴다: `Lv20에 열립니다` |
| 권한·해금 전 | `잠김 — 3층을 넘으면 열립니다` |

## 7. 쓰지 않는 말

- 번역투: `~에 대한`, `~를 통해`, `~되어진다`, `~할 수 있습니다` 남발.
- 시스템 말투: `처리되었습니다`, `적용됩니다`, `진행해 주세요`.
- 감탄·과장: `엄청난!`, `최강의!`, `놀라운 보상!`.
- 폐기 표기: 용어집 "폐기 표기" 표에 있는 말은 화면에 쓰지 않는다.

## 8. 검사

```bash
./.venv/bin/python tools/check_glossary.py --deprecated   # 화면 문면의 폐기 표기 잔재
./.venv/bin/python tools/humanizer_scan.py sim/center/pages   # 화면 문서 번역투 밀도
```

`--deprecated`는 경고다. 같은 철자가 현행 용어와 겹치는 말(`수호` = defend 미션)은 문맥을 보고 손으로 고친다.
