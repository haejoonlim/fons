# 아트 바이블 — 폰즈 (FONS)

시각 규칙의 정본. **아직 대부분 미정이다.** 여기 적힌 것은 이미 코드·렌더로 확인된 것뿐이고,
정해지지 않은 것은 "미정"이라고 적는다. 추측을 규칙처럼 적으면 다음 사람이 그걸 지킨다.

## 확정 (코드·렌더 실측)

| 항목 | 값 | 근거 |
|---|---|---|
| 기준 해상도 | 1280 × 720 | `view_2d` 의 `origin` 기본값 `(640, 360)` (자체 실측) |
| 1 유닛 = | 48 px | `view_2d` 의 `pixels_per_unit` 기본값 (자체 실측) |
| 텍스처 필터 | nearest (밉맵 유지) | `project.godot` 의 `use_nearest_mipmap_filter` (자체 실측) |
| 지금의 표현 | `kind` 별 색 사각형 | 스프라이트 없음 (자체 실측) |

`nearest` 필터를 켜 둔 것은 픽셀 밀도가 낮은 2D를 전제로 한 선택이지, 픽셀 아트를 확정한 것이 아니다.
**아트 스타일 자체는 미정** — 3D 키트의 계약은 아래 "3D 키트" 절에 있고, 셰이딩·조각 수는 아직 안 골랐다. 스프라이트 첫 세트를 뽑을 때 2D 쪽 기준 크기도 여기에 더한다.

## 카메라 (2026-10-25 확정)

3인칭 추적 — 캐릭터 뒤에서 낮게 내려다보는 원근 카메라. 원신·엔드필드가 쓰는 부류를 목표로 했다.
**두 게임 다 FOV·거리·기울기·화면 좌표를 공개하지 않는다.** 아래 수치는 그 게임들의 값을 옮긴 것이 아니라,
우리 월드(캐릭터 키 1유닛)에서 위 구도를 만들려고 고른 값이다 [자체 결정].

| 항목 | 값 | 근거 |
|---|---|---|
| 투영 | 원근, 수직 FOV **50°** | 16:9 에서 수평 약 79°. 정사영 탑뷰 폐기 |
| 거리 | 기본 **4.2** 유닛, **2.8~30** | 캐릭터 1유닛이 화면 세로의 약 1/4. 최대는 28유닛 필드를 한 화면에 |
| 기울기 | 기본 **18°**, **6~42°** | 수평에 가까운 낮은 앵글 — 40° 를 넘으면 다시 탑뷰로 읽힌다 |
| 시선 | 가슴 높이(0.62) + **0.75** 유닛 위 | 캐릭터를 화면 아래 3분의 1에 둔다 |
| 추적 | 초당 9 비율 lerp · 12유닛 넘는 순간이동은 즉시 | 조종 전환·층 이동에서 카메라가 미끄러지지 않게 |
| 조작 | **마우스 캡처** — 움직임 = 시점(0.2°/px · 실측 0.201) · **휠** = 거리(1.15배/칸 · 2.8~30) · **Q/E** = 회전(101°/s) · **Esc** 해제 · 필드 클릭 재획득 | 서브컬쳐 3인칭 표준. 버튼을 누를 필요가 없다. 창을 잃으면 커서를 돌려준다. 최소 2.8 은 흐림 문턱(2.4) 밖이라 끝까지 당겨도 영웅이 안 흐려진다 |
| 휠의 한계 | 프롭이 붐을 묶은 자리에서는 **휠이 화면에 아무 일도 안 한다** (시작 자리: 요청 30 → 9.81 에 카메라 이동 **0.00**유닛) | 프롭 가림 규칙의 당연한 결과지만 플레이어에게는 "휠 고장"으로 읽힐 수 있다. 트인 자리(0, 15)에서 같은 휠은 프레임당 최대 **1.69**유닛 — 스무딩을 생략한 몫이다(붐 풀림 0.30초면 0.2 남짓). 하네스 `tools/shot_zoom_feel.gd` |
| 점프 | **Space**, 최고 **0.63** 유닛, 체공 약 0.6초 | 연출 전용 — 심은 평면이라 장애물을 넘거나 높이를 타지 않는다 |
| 교전 | **F** 또는 Enter | Space 를 점프에 내줬다. 2D 폴백은 Space 도 같이 받는다 |
| 이동 | WASD 는 **화면 기준** | 카메라를 돌리면 걷는 방향도 같이 돈다 |
| 지면 여유 | 필드 사방 **32** 유닛 (`FonsTerrain.MARGIN`) | 최대 카메라 거리(30)보다 넓다 — 최대로 당겨도 판 끝이 화면에 안 들어온다. 플레이 경계는 40×28 그대로. 105×93 정점 · 19,136삼각형 |
| 지면 클리어런스 | 카메라 높이 ≥ 지형 + **0.5** | 지형에 콜라이더가 없어 레이캐스트 대신 높이 함수로 막는다 |
| 프롭 가림 | 키트가 알려 준 **표면별 원통** 앞에서 붐을 끊는다 (여유 0.35 · 높이 1.2 이상 또는 돌) | 콜라이더가 없다. 줄기와 잎을 따로 내야 캐릭터가 잎 밑에 서도 줄기를 피한다 |
| 가림 완중 | 축에서 **반경 + 0.4** 안으로 들어오면 가중치 0→1 로 섞음 | 스침 판정을 그대로 쓰면 목표 거리가 한 프레임 **2.34** 유닛 튄다(실측). 0.8 은 캐노피(1.81) 기준이라 줄기(0.22)가 시점 39.5° 동안 카메라를 당겼다 — 0.4 면 23.5°(각폭의 2.8배). 0.5° 당 붐 변화 최대 0.123유닛 |
| 가림 높이 | 원통은 **3D** — 수평 원 구간 ∩ 높이 밴드 구간, 여유 0.35 도 가장자리에서 0 으로 | 수평 교점만 보고 높이를 나중에 재면 42° 시점에서 캐노피를 "안 막힘" 으로 오판하고 목표가 2.32유닛 튄다. 실측 최대 스텝 2.32 → 0.076 |
| 붐 스무딩 | 당김 지수 시상수 **0.04초** · 풀림 **0.30초** | 끊긴 목표 거리를 그대로 쓰면 카메라가 툭툭 당겨진다. 당김은 빠르게(나무 통과 방지), 풀림은 느리게. 휠 줌·순간이동은 스무딩 생략 |
| 근접 흐림 | 붐 **2.4 → 1.1** 구간에서 조종 영웅을 투명하게 | 카메라가 등에 붙으면 캐릭터가 화면을 덮는다. 1.1 아래는 완전히 가린다 |
| 타격 흔들림 | 교전 한 번에 **0.18초**, 약한 일격 **0.26**유닛 + **롤 2.2° · 피치 0.86°**, 강한 일격(치명타) **0.338**유닛 + **롤 3.7°** (같은 제곱 감쇠) | 짧게 꾾이고 정확히 0 으로 끝난다. 가림 여유(0.35)가 진폭보다 커서 흔들려도 나무를 안 뚫는다(여유 0.012). 회전은 매 프레임 기저를 새로 지어 누적되지 않는다. 두 단계는 피해 숫자가 아니라 심이 실어 보내는 `strike.heavy`(치명타)로 가른다 — 실 피해가 1,000 단위라 숫자 문턱값은 모든 판을 한 쪽에 붙인다 |

## 대기 — 하늘·원경 (2026-10-25 확정)

3인칭 카메라가 지평선을 보여 주면서 배경이 화면의 절반을 차지한다. 단색이면 땅이 어두운 허공에 뜬다.
값은 전부 심이 준 팔레트(`sky`·`light`)에서 파생하고, 뷰가 새 색을 만들지 않는다.

| 항목 | 값 | 근거 |
|---|---|---|
| 하늘 | 천정 = `sky`(낮 명도 0.74), 지평선 = 헤이즈 | 단색 배경 폐기 |
| 하늘 색 | 팔레트가 **낮**을 보장한다 — 명도 `0.74 × TINT_GAIN.y`, 채도 `0.40 × (gain.x 를 1 쪽으로 절반 압축)`, 색상각은 하늘 전용 앵커(한랭 청록파랑 · 고온 옅은 모래빛) | 명도를 `0.10 + 0.05 × gain.y` 로 두었더니 26바이옴이 전부 해 질 녘으로 읽혔다(풀바다 `#1a1e25`). 조명 색온도 축을 그대로 쓰면 고온이 노을이 되어 앵커를 따로 뒀다 |
| 하늘 채도 | **0.40 (상한 0.46)** — 편차는 절반만 따라간다. 실측 평온 0.31(풀바다) · 극한 0.43(먼지벌판) | 0.30 에서는 평온 채도 0.165 로 흐린 낮이었다(2026-10-25 피드백). gain.x 를 그대로 쓰면 풀바다 0.22 ↔ 고온 0.46 으로 벌어져 먼지벌판이 노란 필터가 된다 — 0.46 시트와 나란히 놓고 상한을 0.40 으로 잡았다. 편차를 살리려면 이 상한을 넘기지 않는다 |
| 헤이즈 | `sky` 의 색상각 유지 · 채도 ×0.55 · 명도 → 1.0 쪽으로 62% | 공기 원근은 먼 공기가 밝아지며 색이 빠지는 현상. 태양광 색과 그냥 섞으면 회색 안개가 된다(렌더) |
| 하늘 곡선 | 0.40 (기본 0.15) | 0.15 는 카메라가 보는 43° 아래를 전부 헤이즈로 덮어 회색 판이 됐다 |
| 색 공간 | 팔레트 sRGB → `srgb_to_linear()` 후 하늘·안개 재질에 넣음 | 그냥 넣으면 밝고 창백해진다 — 지형 정점색에서 겪은 감마 결함과 같은 종류 |
| 원경 안개 | 깊이 안개 **38 → 85** 유닛, 색 = 헤이즈, `fog_sky_affect = 0` | 20/58 로 잡았더니 필드 절반이 안개에 먹혔다. 하늘 그라데이는 안 덮는다 |

**확인한 것과 확인 못 한 것**
- 원신: 설정의 기본 카메라 거리 슬라이더가 4.5~6.0 이라는 것, Y축 자동 복귀가 지형을 따라간다는 것까지는
  공개 자료에 있다. 슬라이더 값은 미터가 아니고, FOV·기울기·화면 좌표는 비공개다.
- 엔드필드: 설정에 상대값 −5~+5 의 카메라 거리가 있고, 전투 카메라 보정이 있다는 것까지 확인했다.
  탐험 카메라의 수치도 비공개다. 탑뷰는 AIC 거점 건설용이지 전투 시점이 아니다.

## 파일 규격

- 2D 스프라이트: PNG, 투명 배경. 아틀라스로 묶을 때는 여백 1~2 px을 둬 nearest 샘플링에서 이웃이 새지 않게 한다.
- 3D: glTF 2.0(`.glb`) 또는 Blender에서 직접 임포트. 소스 `.blend` 는 [art-source/](../../art-source/README.md) 에 둔다.
- 이름: snake_case, 원본 파일명과 동일하게 유지.
- 라이선스: 외부 에셋은 출처·라이선스를 `godot/assets/CREDITS.md` 에 적는다.

## 3D 키트 (2026-10-26)

바이옴 지형 키트가 어떤 축·색으로 오는지의 계약이다. 피벗·스케일·격자·부품 이름 규칙은 [바이옴_에셋_계획](../design/바이옴_에셋_계획.md) §6 이 정본이라 여기서 되풀이하지 않는다.

| 항목 | 값 | 근거 |
|---|---|---|
| 회전 기준축 | 정면 **`+Z`** — 뒤로 흘리는 것(잔해·주저앉은 상인방)은 `-Z` | glTF 2.0 규약과 Godot 에셋 규약이 같은 축이다 — 뷰는 yaw 만 돌리면 된다. `-Z` 는 카메라·기본 노드의 전방일 뿐이다 ([스타일_리서치](스타일_리서치.md) §5). 잠금: 생성기 `axis_check()` + `test_the_imported_kit_keeps_its_front_on_plus_z` (무너진 아치 무게중심 z 실측 −0.52) |
| 텍스처 | **0장** — 정점색과 머티리얼 색 | 바이옴 색을 `climate.ambient`·`category` 에서 파생한다. 아틀라스를 넣으면 색이 이미지에 구워져 수치를 바꿀 때 그림이 안 따라온다 ([스타일_리서치](스타일_리서치.md) §2) |
| 아웃라인 | 없음 | 배포 팩 제품 페이지에서 기본 아웃라인을 확인하지 못했다 ([스타일_리서치](스타일_리서치.md) §3) |
| 폴리곤 | 파일럿 값을 유지한다 — 합 650삼각형 (나무 178 · 바위 98 · 둔덕 80 · 프롭 21~105 · 바닥 2) | 배포 팩 공개 범위(나무·목재 20~919 · 바위 8~400) 안쪽이라 상한을 올릴 근거가 없다 ([스타일_리서치](스타일_리서치.md) §1) |
| 셰이딩 | **미정** — 지금은 지형이 높이 함수 중심차분 법선, 부품은 상자만 면 법선이고 구·원기둥·원뿔은 스무스 | 배포 팩 세 곳이 셰이딩 방식을 공개하지 않아 비교할 근거가 없다. 후보 셋(A 유지 / B 전부 플랫 / C 툰)의 실렌더 대조 시트는 [셰이딩_조각수_선택지](셰이딩_조각수_선택지.md) §3.5 — C 는 `gl_compatibility` 에서 도는 것까지 확인됐다 |
| 모듈 조각 수 | **미정** — 파일럿은 바닥 4 · 높이 2 · 랜드마크 1 · 프롭 4 | 3D 키트의 업계 공통 조각 수가 확인되지 않았다 |

**축을 몸으로 보이는 부품은 하나뿐이다** — `topo_urban_ruins` 의 무너진 아치. 상인방이 뒤(`-Z`)로 빠져 있어 앞뒤가 화면에서 갈린다. 대칭 부품만 있는 동안은 축이 화면에 안 드러나므로, 계약을 보이는 부품을 하나 남겨 두고 생성기·GUT 양쪽에서 부호를 지킨다.

- UI 테마(폰트, 여백, 모서리)
- 몬스터 파츠 조합 규칙 — 원본 기획에 파츠 개념이 있으나 이 저장소에는 구현이 없다
