# 몬스터 이름 점검 — 전수 목록

작성 2026-10-23 · 상태 **20건 적용 완료 (확정 15 · 검토 5)**, 드라코리치 1건은 현행 유지 · 범위 전투 143 + 비전투 234 = 377종

`적갈래매 → 적갈매` 때 쓴 기준을 전 종에 적용한 결과다. 여기 적힌 이름은 **정본이다** (data/ 반영 완료).
적용 전 표기는 [용어집 폐기 표기](../l10n/용어집.md) 에만 남긴다 — 본문·UI에 다시 쓰지 않는다 (AGENTS.md §1).

## 1. 기준

1. **한국어로 읽히는가** — 없는 형태소, 오역, 겹말이 없는가.
2. **계열과 꼴이 맞는가** — 색+종(`초록슬라임`), 수식어+매(`폭풍매`), 3단 정령 같은 기존 꼴.
3. **용어집 폐기 규칙을 지키는가** — 괄호 색상, 역할 접미, 뜻 없는 음차, 이름 안의 별칭(`·`).
4. **이름이 행동·서식과 맞는가** — wraith를 `형태`로, eel을 `수명`으로 옮긴 것 같은 어긋남.

전수 스캔 결과 377종 이름 중복 0건. 기계적으로 걸러낸 것: 괄호·가운뎃점 3건(§2 전부 후보),
7음절 이상 13건(후보 4건 + §4의 계열·통용어·한국어 합성 9건), 공백 포함 144건(비전투 서술형 규칙, §4).

| 유형 | 예 | 왜 |

| 정령 3단 계열 | 화구정령 · 불꽃대정령 · 용암정령왕 / 성광정령 · 거광대정령 · 무량정령왕 | 계열 안에 규칙이 있다. `거광`·`무량`은 뜻이 흐리지만 한 칸만 바꾸면 삼단이 깨진다 |

## 5. 적용 순서 (실행한 그대로)

이름 하나당 아래를 한 묶음으로 했다 (적갈매 선례와 같다).

1. **데이터**: `data/ambient.json` 또는 `data/monsters.json` 의 `name`, `data/ecology_codex.json` 의 `name`.
2. **사본**: `godot/data/` 같은 파일 복사.
3. **생성물**: `./.venv/bin/python sim/center/sync_pages.py --write`.
4. **용어집**: `docs/l10n/용어집.md` 폐기 표기 표에 `옛 이름 | 현행 | 근거` 한 줄.
5. **대조표**: `./.venv/bin/python tools/check_gdd_names.py --write`.
6. **검증**: `check_glossary.py`, `check_monsters.py`, `check_docs.py`, `gate_all.py`.

GDD 02·07·08 에 적용 전 표기가 남아 있는 건은 [GDD 이름 대조표](../l10n/GDD_이름_대조표.md) 가 장부다
(`check_gdd_names.py --write` 로 다시 뽑는다). 원본 문면은 고치지 않고 개정 요청 목록으로만 남긴다.
