# 관통 데이터 연결 — 12종 중 11종의 pen 이 전투에 닿았고, 레비아탄은 12로 낮춰 100층 승률을 지켰다

한 줄: `unit_from_monster` 가 `pen` 을 0.0 으로 고정해 데이터의 관통이 버려지고 있었다. `stats.pen` 을 읽게 고치자 폭풍거인(80·90)과 레비아탄(96·100) 문지기가 무거워졌다. 100층은 관통 이전 20시드 18승이 14승이 됐고, 레비아탄 pen 을 12로 내려 18승을 되돌렸다([100_레비아탄_관통_조정.md](100_레비아탄_관통_조정.md)). 일반 조우 표는 그대로다.

## 0. 고친 것

`FonsBattle.unit_from_monster` 의 `"pen": 0.0` 하드코딩을 `"pen": float(s.get("pen", 0.0))` 로 바꿨다. 관통은 퍼센트(0~100)이고 `resolve_physical` 이 `/100` 으로 방어를 깎는다. 데이터 12종이 이미 `stats.pen` 을 갖고 있었는데(8~30) 엔진이 안 읽었다.

- 나머지 11종은 7~28% 피해가 올랐다.

- 80·90층은 승패 그대로, 생존만 0.1~0.4/5 내렸다.

## 3. 일반 조우 표는 안 바뀌었다

`floor_report --floors` 130층 표가 수정 전후로 **한 줄도 안 바뀌었다.** 관통종이 실제로 나오는 층은 3~12·21~27·36~37·53~60 이다.

- 초·중반 층은 턴 수가 영웅 화력이 정하고(적을 빨리 지우면 턴이 줄지 적 피해는 무관), 영웅이 죽지 않는다. 그래서 적 피해 7~28% 상승이 턴·승패에 안 나타난다.
- 끝까지 가는 판(96·100 문지기)에서만 생존이 흔들린다.
