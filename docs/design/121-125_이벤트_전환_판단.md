# 121~125 이벤트 전환 판단 — 찢긴 천창을 문지기 판으로

측정 2026-10-28 · 갱신 2026-10-29 (문지기 판 파티 고정 — §4-2) · 근거 `data/biomes.json` · `data/monsters.json` · 도구 [floor_report.gd](../../godot/tools/floor_report.gd) `--gk` · [ecology_report.gd](../../godot/tools/ecology_report.gd) `--full` · 선행 [상층_벽_손잡이_스윕.md](상층_벽_손잡이_스윕.md) §4 후보 (c) · [이데아_문턱_엔딩전투_설계.md](이데아_문턱_엔딩전투_설계.md)

121~125(찢긴 천창)를 126~130(이데아 문턱)처럼 `noCombat` 이벤트 전투로 바꾸면 무엇이 달라지는지 조우 편성·보상·난이도 셋으로 나눠 잰다. 결론을 먼저 적고 근거를 뒤에 붙인다.

## 1. 결론

1. **지금은 전환하지 않는다.** 전환은 이긴 층을 한 층도 늘리지 않는다. 121~125 가 이미 0승이라, 바뀌는 것은 패배가 면제로 옮겨 가는 장부뿐이다 (§4-1).
2. **효과는 111~120 을 뚫은 뒤에만 나타난다.** ★7 5인도 111~120 에서 0승 7패 3무다. 121 에 닿지 못하므로 그 위를 어떻게 바꾸든 지금은 아무도 못 본다.
3. **전환하면 문지기가 셋이 된다.** `monsters.json` 에 보스 모드로 걸린 121 침묵의 군주 · 124 백열파수꾼 · 125 장부군주다. 바이옴 단위 `noCombat` 하나로는 하나만 고를 수 없다. 장부군주는 127 에서 또 선다.
4. **★5 의 500턴 무승부는 121 이 아니라 표본 값이었다 (2026-10-29 정정).** 예전 표는 층마다 다른 파티를 뽑아 121 행이 저체력 파티를 받았다. 같은 파티로 다시 재면 121 은 승 223턴(4인) · 113턴(5인)이고, 시드 1 에서 상한에 걸리는 곳은 128·130 이다. 파티 10개로 늘리면 **125·127 이 승 2/10**(적용 전) 으로 더 자주 막았다. 2026-10-29 장부군주 MAG 250 적용 후 둘 다 7/10 이다 (§4-2 · [121_침묵의_군주_교착.md](121_침묵의_군주_교착.md) §12).
5. **순서는 곡선 → 스킬 → 전환이다.** 전환은 벽을 여는 손잡이가 아니라, 열린 문의 모양을 정하는 변경이다.

## 3. 전환하면 코드가 하는 일

데이터 한 줄이면 126~130 과 같은 경로를 탄다. 코드 변경은 없다.

| 단계 | 지금 (121~125) | 전환 뒤 |
|---|---|---|
| 조우 계획 | `plan_for_floor` 후보 5종 | `no_combat` 표시 · 후보 0 |
| 필드 | 일반 조우 3곳 | `_combatless` + `_gatekeeper` |
| 진행 조건 | 조우 3곳 제거 | 문지기 격파 (문지기 없는 층은 통과) |
| 결투 | 없음 | 121·124·125 에서 F |
| 보상 | 없음 | 첫 격파 1회 `loot` |

122·123 은 문지기가 없어 `mission_done()` 이 즉시 참이다 — 전투 없이 다음 층으로 넘어간다. 129 와 같은 규칙이다.

## 5. 실측 — 조우 편성

- 지금 121~125 는 다섯 층이 **같은 편성**이다 — 들바람정령 · 산바람대정령 · 하늘바람정령왕 · 무게 없는 벌레 · 어긋난 눈 (먹이 1 · 포식 1 · 분해 0 · 밖 3). 층마다 같은 5종이라 다양성은 이미 1이다.
- 전환하면 편성 15개가 0이 된다. 총 편성 **375 → 360** (`ecology_report` 요약).
- **세 종이 어느 편성에도 안 나온다**: 하늘바람정령왕 · 무게 없는 벌레 · 어긋난 눈. 전수 확인 결과 이 셋이 나오는 편성은 121~125 뿐이다. 들바람정령과 산바람대정령은 116~120 이 이웃 차용으로 이미 부른다 — 2026-10-28 재확인, 산바람대정령은 116~120 접촉 2 에 있다. (초판은 넷으로 적었고, 재확인에서 산바람대정령을 뺐다 — [111-120_이벤트_전환_비용.md](111-120_이벤트_전환_비용.md) §3.) 천창 중력 벌레는 지금도 편성에 없다.
- 도감 항목은 남는다 — 사라지는 것은 편성 출현이다.
- 122·123 은 문지기도 없어 **전투 없이 지나가는 층**이 된다. 상층 10층 가운데 3층이 그렇다.
- `missionWeights` 는 남는다. 값을 비우면 `tools/check_manual_fields.py` 의 예외 목록(`biome_idea_gate` 하나)에 25바이옴을 더해야 한다. 그대로 두면 게이트는 통과하지만 "미션이 없는 바이옴에 미션 배분이 있다"는 낡은 데이터가 된다.

## 6. 실측 — 보상

- 지금 일반 조우는 gold 를 안 준다. `godot/game/main/main.gd` 가 지갑에 넣는 곳은 문지기 첫 격파 하나다.
- 전환하면 121·124·125 첫 격파가 각 6,000 gold — **한 런에 18,000** 이 121~125 에서 나온다. 126~130 이 이미 4판 24,000 이므로 상층 10층 수입은 24,000 → 42,000 (+75%).
- ★5 는 121(무승부) · 125(패배)에서 못 받는다. 이 18,000 은 ★7 전용 수입이다.
- `soul` · `exp` 는 지갑이 없어 로그에만 적힌다 — 126~130 과 같은 한계다.
- 121~125 는 지금 수입 0 인 구간이다. 전환은 "어려워져서 보상이 는다"가 아니라 **"모드가 바뀌어서 보상이 생긴다"** 이다.

## 11. 한계

- 세 조건만 쟀다 (★5 4인 · ★5 5인 · ★7 5인). 파워크리프 중간 배율은 안 쟀다.
