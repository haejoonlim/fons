이번 라운드의 이름 규칙

41차는 뜻을 살리려고 긴 서술형 이름을 썼는데, 나무 전체의 톤(버팀·요새·돌파·급독·중독·낙인)과 따로 놀았다. 이번에는 두 글자 동작·명사로 맞췄다.

되살린 이름 셋 — 중갑(체력) · 몰이(민첩) · 선회(민첩). 죽은 이름 목록에서 빼서 다시 쓸 수 있게 했고, 41차에 만든 긴 이름들은 목록에 넣어 되살아나지 않게 했다.

사역사 — 생태도감 근거

세 장을 각각 실제 서식종에 붙였다. 늑대(6~10층 · 숲·평원) = 물기 · 들매(1~5층 · 초원) = 몰이 · 표류수리(11~15층 · 산호·바다) = 등짐.

'사역사'는 사전에 없는 조어다. 이름은 지정대로 두고, 직업 설명이 뜻을 바로 풀게 썼다. 자연스러운 대안은 야수 조련사.

창술사 — 자리를 옮겼다

작살꾼(원래 마궁사 자리)을 지우고 전사 » 창술사로 옮겼다. 궁수는 다시 세 갈래(명사수·포화사수·사역사), 전사는 여섯 갈래가 된다.

직업 id 는 l2_magearrow 그대로다 — 키워드 배율표가 id 를 키로 쓰기 때문에 id 를 바꾸면 세 카드의 power 가 초기값으로 떨어진다. 주석으로만 남겼다.

땜장이 — 왜 새 직업인가

전투 중에 아군의 갑옷과 무기를 고친다. 사람을 낫게 하는 치유(성술사·신관)도, 명령을 내리는 지휘(전술가)도, 적의 상태를 바꾸는 정신술사도 아니다.

L4 적성 대장장이와 구분된다 — 대장장이는 영지에서 만들고, 땜장이는 전장에서 때운다.
