## 4. 검사기(`tools/review_docs.py`)를 고친 곳

검사 지적을 줄이는 방법은 두 가지뿐이었다: **문서를 고치거나**, **검사 규칙이 실제로 틀렸던 지점을 바로잡거나.**
점수를 만들려고 검사를 약하게 만든 적은 없다. 아래는 규칙을 고친 6곳이다.

| # | 고친 것 | 왜 결함이었나 | 방향 |
|---|---|---|---|
| 1 | 결정 번호(`D-265`)를 숫자 주장에서 제외 | 인용 부호를 값으로 읽었다 | 정밀도 (자체 실측) |
| 2 | 한글이 붙은 결정 번호(`D-267이`) 인식 | 경계 문자(`\b`) 때문에 아예 놓쳤다 | **탐지 강화** (자체 실측) |
| 3 | 문서 이름 안의 원본 계획 파일명 오인 제거 | `DEV_PLAN.md` 안의 `PLAN.md`를 원본 표지로 봤다 | 정밀도 (자체 실측) |
| 4 | `SHAPED_RATE`·`LEGACY_RATE` 꼬리말 충돌 제거 | 이름 꼬리말로 묶어 **다른 상수**를 같은 것으로 봤다 | 정밀도 |
| 5 | 표 행이 윗 행의 출처 표시를 물려받지 않게 | 표시 없는 주장이 면제로 새어 나갔다 | **탐지 강화** |
| 6 | 문서 절 참조(`§9`)를 숫자 주장에서 제외 | 인용 부호를 값으로 읽었다 | 정밀도 |

**출처 표시 어휘는 늘었다** — `(원본 미검증)` 하나였던 것을 세 가지로 나눴다:
`(원본 대조)` 원본에서 읽은 값 · `(자체 실측)` 이 머신에서 측정한 값 · `(원본 미검증)` 아직 확인 안 됨.
이건 면제를 늘리는 변경이 **아니다** — 표시가 아예 없으면 세 경우 모두 발견이다.
`(원본 미검증)`을 붙이면 거짓이 되는 줄(우리가 직접 잰 HTTP 응답 등)에 정직한 표시를 주려고 만든 구분이다.

## 7. 아직 안 한 것 (이 검수의 한계)

1. **원본 데이터 이관은 끝났다** — 17종을 `data/`와 `godot/data/` 양쪽에 복사했고, `tools/check_docs.py`가 누락을 잡는다 (자체 실측).
   남은 것은 그 데이터를 읽어 게임을 돌리는 시뮬 코어 포팅이다.
2. **원본의 미정 항목은 미정으로 남겼다.** 천장 수치는 원본에서도 가안이고, ★7 초월진화 조건은 원본에 없다.
   우리가 채워 넣으면 그건 설계가 아니라 날조다 (원본 대조).
3. **Unity C# 구현은 검토하지 않았다.** 버리는 쪽이라 판단했지만, 로직이 GDScript로 옮겨질 때
   원본과 다르게 동작하는지는 **아직 아무도 확인하지 않았다.**
4. **3D 성능은 여전히 미측정이다.** 60fps는 목표일 뿐이다.
5. **상수 단일 소스화는 아직 안 했다.** 값이 확정됐으니 이제 할 수 있다 — `SHAPED_RATE` = 0.05 와
   `LEGACY_RATE` = 0.95 가 `sim/gacha.py`·`godot/scripts/sim/gacha.gd` 두 곳에 각각 있다.
