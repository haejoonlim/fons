> **측정법에서 걸린 함정 하나 (중요)** — 처음에 ②번을 "분해자↔(먹이·포식) **종간** 간선"으로 좁혔더니 26바이옴 중 **11개**가 단절로 나왔다. 그런데 08 §6 표의 note "자원 간선은 종간 집계에서 제외"는 **간선 개수**의 정의다(종 쌍을 세는 것이라 자원을 세면 364 종 전부가 `corpse` 로 한 번씩 올라간다). **사슬 연결 판정은 다르다** — 08 §5 원칙 5 는 "모든 죽음은 `corpse` 자원으로, 분해자가 섭취" 를 규칙으로 박아놨고, §6 표가 ✅ 찍은 대표 바이옴들이 바로 그 연결을 제시한다: 서고의 핵심 경로 "먹광→글자벌레" 는 먹광이 **자원**이고, 사막의 "썩고기갑충 사체 청소" 도 사체가 **자원**이다. 즉 문서 스스로 자원 간선을 사슬의 링크로 인정한다. 그래서 ②번에 자원을 인정하니 결함은 **11 → 1** 로 줄었다. 남은 결함만 진짜였다.

> 2026-09-29 먹이층 "천적 0" 전수 해소 — 바이옴 단위 게이트 밑에 더 좁은 결함이 있었다. **아무도 안 먹는 먹이층 종 46종**(23바이옴). 압력화구와 같은 종류다. 간선 46개 추가 → **종간 간선 248 → 294** · 종수 변동 0(364 = 13×28).
> **판정의 함정 — 216이 아니라 46인 이유.** 08 §5 원칙 2 를 문자 그대로 "먹이 1 + 천적 1" 로 읽고 면제를 producer·apex 만 적용하면 **171종**이 위반으로 나온다. 하지만 ① 프로젝트가 실제로 검사하는 `check_docs.py` 의 고아 판정은 `prey=0 AND predators=0` 이고 그것이 0건 — **천적 0 은 지금까지 검사된 적이 없다.** ② 07 §3 은 "**guardian 역할은 생물 포식 사슬 밖의** 특수 역할" 이라 명시하며 guardian 23종은 사슬 밖이라 천적이 없어야 정상이다(08 §5 도 elemental·mimic 을 그물 제외로 적고, 06 §3.5-2 는 `elemental·guardian·undead` 를 온도 스폰 게이트에서 제외). ③ 결정적 — **사슬이 끊기는 건 먹이층 종이 안 먹힐 때다.** 상위 포식자나 분해자가 천적 0 인 것은 포식 사슬의 **정상적인 정점**이다(무는 이 무리를 먹지 않는다). 그걸 결함으로 보면 "먹이 10 → 포식 1"(§7) 구조를 스스로 무너뜨린다. 그래서 판정을 "**먹이층 종이 전역 predators 0**" 으로 좁혔다 — 이것만 잡아도 먹이층이 고립되어 사슬 바닥이 끊긴다.

> 규칙 (D-261 — 층=생태계 · 웨이브 폐지, 2026-09-18): 층은 하나의 생태계이자 하나의 새로운 세계 — 탑이 층 진입 시 미션 1개를 부여하고, 전투는 "생태 조우"로 표현한다. **조우 모드** = `encounter`(생태 조우 — 일반 전투 미션 풀) / `elite`(정예 조우 전용) / `boss`(보스 후보 · 게이트키퍼층 5/10/15/20에서 tier4 이상 1체, 그 외 층은 게이트 아님) / `world`(비전투 — 어떤 층 전투에도 제외) · `elite: true`는 정예 수식(28종 — P3-6 모디퍼 뼈대)
> 규칙 (D-265 — 층 미션 시스템 확정, 2026-09-19): ① **오픈월드 탐험형 진입** — 게이트 통과 → 전경(풍경 노출) → 지역 타이틀 카드「<바이옴명> 지역」 → 탑의 미션 부여 → **유닛 직접 조작 탐험 개시** (조우는 접촉/발견 트리거 — 정해진 순서 없음) ② **미션 5종 + GK** — 정찰(scout)/토벌(purge)/수호(defend)/수집(gather)/정예 사냥(elite_hunt) + 게이트키퍼 토벌(gate — GK층 5/10/15/20 고정) · 일반층은 5종 층·바이옴 가중 랜덤(시드 고정 — 미정J) ③ **보상 귀속 — 탑의 미션 보상 = 마석 한정** (층 30f·GK 잭팟·소형 — D-252/G+E 정본 총액·타이밍 무변경, 출처 귀속만 재정의) · 골드·재료·드롭은 **층 탐험 획득** ④ 클리어 = 미션 달성 · 실패 시 즉시 재도전(탐험 진행 유지) · 전멸은 기존 귀환 규칙 승계. 상세 — [[D-265_층_미션_시스템]] · `missions.json` 가안 파라미터는 플탐 튜닝 대상
