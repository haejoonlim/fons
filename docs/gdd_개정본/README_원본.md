## 폴더 구조

```
design-docs/
├── README.md                ← 이 파일 (진입점)
├── AGENTS.md                ← 에이전트·작업자 필독 규칙
├── GDD_v8.0_*.md            ← 게임 규칙 정본 (00~09 + 99)
├── 설계/                    ← 확정 상세 설계 (승격분 · README에 대응표)
├── 제안서/                  ← 미확정 제안 (승격 시 설계/ 또는 _기록/으로 이동)
├── _기록/                   ← 검수·검증·측정 기록 + 테스트 실행 가이드
├── 결정로그/                ← 결정 단위 ADR (D-251~ · README에 인덱스)
├── _tools/check_docs.py     ← 정합 검증 (exit 0 = 준수 · 데이터 커밋 전 게이트)
├── _tools/gate_all.py       ← 통합 게이트 — 커밋 직전 전체 검증
├── _tools/sim_*.py          ← 경제·생태·미션·층 곡선 시뮬레이터
├── _템플릿/                 ← 문서 서식
└── 발주/                    ← 외부 에셋 발주 프롬프트
```

## 규칙 한 줄

- **v8.0만 정본.** 구 Godot 기준 문서는 2026-09-21 전부 삭제했다 — 근거로 인용할 대상이 없다.
- **미정 항목은 추측 금지** — `GDD_v8.0_00_확정사항.md`의 "미정" 절을 확인하고 사용자에게 질문.
- 확정 설계는 `설계/`, 아직 판정 전이면 `제안서/` — 다 쓰고 나서 폴더를 고민하지 않는다.
- 새 문서는 `_템플릿/`에서 시작하고, 작성 후 이 README와 `AGENTS.md` §2 표에 등록한다.
