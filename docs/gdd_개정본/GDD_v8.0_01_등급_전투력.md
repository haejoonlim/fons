## 3. 전투력(CP) 공식 v1.0 가안

```
S = HP×0.12 + ATK×2.0 + MAG×2.0 + DEF×1.5 + MDEF×1.5
  + ASPD×3.0 + CRI×3.0 + CDMG×1.0
  + PEN×2.5 + MPEN×2.5 + MS×1.5 + MANA×0.05 + STA×0.03  … ① 기본스탯점수 (13축 — 05 §7 동기화)
  # 38차: EVA 삭제 → MS(이동속도) 신설 · MPEN 항 추가 · SPD_CAST 는 CP 축에서 뺐다
  #       (35차 후속5 에서 시전속도를 공속에 통합 — 런타임 스탯으로는 남는다)
G = S × 등급계수(§2) × 레벨계수(기존 곡선)              … ② 성장점수
E = 장비 스탯의 ①식 합산                               … ③ 장비점수
K = 스킬 합산 (일반1 / 희귀2 / 영웅3 / 전설5 / 신화8)   … ④ 스킬점수
P = 성격보정 0.95~1.10 (§4)                            … ⑤
C = 상태보정 0.80~1.10 (사기·스트레스·Sanity 합성)      … ⑥
R = 공명보정 1.00~1.10 (해당계열 편성 3명마다 +5%, 상한) … ⑦
Y = 파티시너지 0.90~1.15 (조합 보너스 — 00 #42)          … ⑧ 2026-09-19 신설

CP = round((G + E + K) × P × C × R × Y)
파티CP = 출격 5명 합산
```

- **CP는 날것(raw) 수치.** 상성·지형·위치보정은 실전 보정으로 제외.
- **⑧ 파티시너지 S_syn (00 #42 — 2026-09-19 사용자 결정)**: 개인별 아닌 **파티 단위 승수** — 파티CP = Σ개인CP × Y 로 적용 (개인 카드 CP는 Y 미포함 유지 — 뽑기 화면 무변경). 조합표: 성격 케미 +2~3% · 불화 −2~4% (스트레스 연계 +25%/쌍 — 04 §3.6-2) · 계열 다양성 4/5/6종 +2/3/4% · 직업 중복 3+ −2% · 특성 공진 +1.5%/특성(상한 +3%) · clamp 0.90~1.15. 몬테카를로 10만 (party_synergy_sim.py): 무작위 평균 +1.1% · 이상 조합 +10.5% · 최악 −8.0%
- ③ 장비 최소 세트 가안 (P3-3, 2026-09-14): 3슬롯(무기·방어구·장신구) × 3등급 = 9종 · 강화 +0~+10 · +1당 기본치 +10% · 강화비 골드 100×다음단계 → `data/equipment.json` · 획득 = 허브 상점 골드 구매 (하급 200 · 중급 800 · 상급 2,000G 가안) · 사망 시 보관함으로 반환
- ④ 스킬 (P3-4, 2026-09-14): 슬롯 구조만 — K = 희귀도 점수 합, 스킬 데이터·획득은 후속 (현재 K=0)
- 권장CP 가안 (P3-4, 2026-09-14): 해당 층 적 편성의 ①식 점수 합 × 1.0 (게이트키퍼는 보스 스케일 반영) · **유효CP는 지형 상성 데이터가 생길 때까지 날것과 동일 표기**
- 표시: `CP 12,400 (유효 ~13,800, 수해지형)` — 날것 + 예상유효 병기.
- 용도: 게이트 입장 권장CP · 오토매칭 · 랭킹. 입장 제한(컷)은 두지 않음 (도전 허용).
