# 문서 전체 검수 — 2026-10-24

전체 문서를 기계 검사 7종과 손 대조로 다시 봤다. 목적은 **모순 · 결함 · 빈틈을 찾아 고치는 것**이고,
고칠 수 없는 것(원본 문면·생성물)은 고치지 않고 목록으로 남긴다.

없는 경로를 "미래 산출물"로 통과시키고 있었다.

## 1. 검수 방법 (그대로 재현)

```bash
./.venv/bin/python tools/review_docs.py          # 문서 7검사 (advisory)
./.venv/bin/python tools/check_docs.py           # 필수 산출물 · 데이터 사본
./.venv/bin/python tools/check_glossary.py       # 표기 317건 대조
./.venv/bin/python tools/check_gdd_names.py      # GDD 잔재 (advisory)
./.venv/bin/python tools/gate_all.py             # 통합 게이트
./tools/test_godot.sh                            # GUT 318
```

손 대조는 세 방향으로 했다.

1. **같은 사실이 두 문서에 다른 값으로 적힌 곳** — 130층 표, 테스트 수, 데이터 종수, 턴 상한.
2. **문서가 가리키는 경로가 실제로 있는가** — `godot/`·`sim/`·`tools/` 경로를 전수로 풀어 봤다.
3. **문서 색인이 실제 문서를 모두 담고 있는가** — `docs/README.md` 링크와 파일 목록을 대조했다.

### 3-1. 정리 뒤에 실제로 드러난 것 (2026-10-24 적용)

면제 목록을 실제 트리 기준으로 다시 쓰자 검사기가 **17건**을 잡았다. 전부 문서 쪽에서 고쳤다.

| 드러난 것 | 처리 |
|---|---|
| DEV_PLAN·MIGRATION_PLAN·PORTING_MAP 이 `summon.gd`·`world/*` 를 가리킴 | `gacha.gd`·`view/view_3d/` 로 정정. 엉뚱하게 적힌 WBS 상태(소환·전투·영지·3D)도 실제로 맞춤 |
| `godot/assets/CREDITS.md` 가 없다 | 파일을 만들었다 (외부 에셋 없음 명시) |
| 없어진 도구·스크립트 이름(`job_ai_sim.py` · `audit_sim.py` · `references/` 안 파일들) | 파일명만 남겨 경로 주장을 빼거나 "없음"을 문장으로 씀 |

### 3-2. 검사기 자체를 고친 곳 2

| 고침 | 왜 |
|---|---|
| 참조를 **문서 자기 폴더 기준**으로도 풀게 함 (`classify_ref(..., doc_dir)`) | `sim/center/README.md` 의 `gacha_test.py` 같은 이웃 파일 참조가 "없는 파일"로 오탐되던 것 |
| `.claude/`·`.agents/` 를 검사 대상에서 제외 (`SKIP_DIRS`) | 외부 스킬 문서는 우리 문서가 아니고, 자기 번들 안 경로를 가리킨다 |

둘 다 **탐지를 약하게 만든 변경이 아니다** — 오탐을 줄였고, 면제 목록 정리와 함께 같은 실행에서 17건을 새로 잡았다.
`review_docs.py` 는 여전히 advisory 다. 하드 게이트로 올리면 문서를 쓰는 동안 면제 표시 하나 빠진 줄이
곧바로 실패가 되고, 그 압력이 검사를 약하게 만든다 (DOC_REVIEW §5 의 판단을 그대로 둔다).
