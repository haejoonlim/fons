### 이식하며 원본과 달라진 곳 (2026-10-24)

원본 `check_cjk_injection` 은 `design-docs/` 문서 전체를 훑는다. 폰즈는 **문서를 빼고 코드·데이터를 훑는다**.

- `docs/gdd/`·`docs/original/` 은 원본 문면이라 고칠 수 없다(docs/README.md 규칙 2). 실패로 만들면 사람이 원본을 손대게 된다.
- `docs/dev/` 는 이력 서술에 한자를 인용한다.
- 대신 원본이 놓친 자리를 본다: `data/*.json`·`godot/**/*.gd`·`tools/`·`sim/`. 이식 직후 **실제 유입 3건**이 나왔다 — `data/basic_attacks.json` 의 铺, `godot/core/run_state.gd` 의 、职业, `promotion_lab.html` 의 接线. 셋 다 고쳤다.
- 제외 구간(`docs/`, `sim/center/sims/`, `.claude/`)은 **파일 수로 보고**한다. 조용히 스킵되면 아무도 확인하지 않는다.
- `check_no_hardcoded_path` 는 코드의 **주석·독스트링을 지운 뒤** 본다. 원본 클론을 부른 기록은 이력이지 잔재가 아니다. 예외는 줄 끝 `path-ok` 와 [ALLOW_FILES](../../tools/check_paths.py) 뿐이고, 둘 다 사유가 코드에 남는다.
- `check_manual_fields` 의 대상은 원본과 같은 세 파일(`biomes.json`·`monsters.json`·`ambient.json`)이다 — 폰즈에서 유일하게 사람이 스키마 밖 값을 채우는 곳이기 때문. `ambient` 에는 `level` 이 없다(비전투 개체). 예외는 `biome_idea_gate` 의 `missionWeights` 하나뿐이고 사유가 코드에 있다.
- `manual_values_baseline.json` 은 **커밋된 정본(HEAD e5c1eaa)** 에서 만들었다(2026-10-24, `--from-head`, 사유 기록됨). 그래서 지금 진행 중인 미커밋 데이터 변경 31건은 WARN(rc 0)으로 남고, 그 변경이 커밋된 뒤 기준선을 갱신하지 않으면 FAIL 이다. 갱신은 `--update --reason "사유"` 필수.
